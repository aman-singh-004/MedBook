# MedBook - Full-Stack Appointment Booking System

MedBook is a lightweight, responsive, and aesthetically premium full-stack **Appointment Booking System** designed for clinics and doctors.

This project follows the **MVC (Model-View-Controller)** pattern, separating concerns cleanly across the Spring Boot backend and native Vanilla JS frontend. It is configured out-of-the-box to run using an in-memory **H2 database**, allowing you to run the system with **zero database installations** required!

---

## 🌟 Key Features

1. **User Authentication**: Secure signup and login with hashed passwords (BCrypt) and a custom token-based session management system.
2. **Patient Dashboard**: 
   - Book appointments with dynamic date & time-slot selection (disables already-booked hours).
   - View scheduled appointments (filter by status).
   - Reschedule or cancel appointments.
3. **Admin Dashboard**:
   - Manage doctor rosters (Add, edit, delete doctor profiles).
   - Confirm, complete, or cancel patient appointments.
   - View clinic statistics (Total bookings, active doctors, total patients, status counts).
4. **Collision Prevention**: Prevents double-booking a doctor for the same date and time slot.
5. **Modern UI**: Dark-mode/Glassmorphism theme built using responsive CSS grids, HSL values, Google Fonts (`Outfit` & `Inter`), and interactive animations.

---

## 🛠️ Technology Stack

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6), API Fetch Client
* **Backend**: Java 17, Spring Boot 3.3.0, Spring Data JPA, Hibernate, H2 Database (with optional MySQL integration), Validation, BCrypt Hashing
* **Build Tool**: Maven

## ⚙️ Setup & Installation Instructions

### 1. Database Setup (Plug-and-Play)
By default, the application uses an **in-memory H2 database**. 
* **Zero installation required**: You do not need to install MySQL, PostgreSQL, or any other server.
* **Auto-creation**: Tables are automatically generated by Hibernate on startup.
* **Auto-seeding**: The database is automatically loaded with test users and doctors on launch.
* **H2 Database Console**: You can view and query the database tables in your browser at `http://localhost:8080/h2-console` using:
  - **JDBC URL**: `jdbc:h2:mem:appointment_db`
  - **Username**: `sa`
  - **Password**: (leave blank)

> **Optional MySQL Deployment**: If you install MySQL later, open `backend/src/main/resources/application.properties`, uncomment Section 2, comment out Section 1, and import `database/schema.sql` into MySQL.

### 2. Running the Backend Server
1. Navigate to the `backend/` directory in your command prompt:
   ```bash
   cd backend
   ```
2. Build the project using Maven:
   ```bash
   mvn clean install
   ```
3. Run the Spring Boot application:
   ```bash
   mvn spring-boot:run
   ```
   The backend will start and listen on port `8080`. You should see terminal logs indicating the application has seeded the default users and doctor profiles.

### 3. Running the Frontend
* Open the `frontend/` folder.
* Double-click `frontend/index.html` to open it directly in your browser. (Alternatively, run a simple local web server like VS Code's "Live Server" extension, or run `npx http-server ./frontend` to view it on a local port).

## 🧪 Testing Instructions

Follow this sequence to test the entire application workflow:

### 1. Log in as an Administrator
* Open the frontend landing page.
* Select the **Log In** tab.
* Enter the preseeded Admin credentials:
  * **Username**: `admin`
  * **Password**: `admin123`
* Click **Log In**. You will be redirected to the Admin Dashboard.
* **Verify**: The statistics cards will show global counters (Bookings: 0, Active Doctors: 3, Patients: 1).
* Click the **Manage Doctors** tab and click **Add New Doctor** to register a new physician profile.

### 2. Register a New Patient
* Log out of the admin panel.
* Select the **Sign Up** tab.
* Register a new user:
  * **Username**: `alice_smith`
  * **Email**: `alice@example.com`
  * **Password**: `alice123`
  * **Role**: `Patient / Client`
* Click **Sign Up**. Switch back to the **Log In** tab and enter Alice's details to log in.

### 3. Book an Appointment
* Inside Alice's Dashboard, click **Book New Appointment**.
* In the modal:
  * Select a doctor (e.g., **Dr. Sarah Connor**).
  * Choose a future date.
  * Select an available time slot (e.g., **10:00**).
  * Write a note (e.g., "Routine health checkup").
  * Click **Book Appointment**.
* **Verify**: The appointment appears in the table with status `PENDING` and your dashboard total statistics update.

### 4. Test Double-Booking Prevention
* Keep the modal open or click **Book New Appointment** again.
* Select **Dr. Sarah Connor** and choose the **exact same date and time slot (10:00)**.
* Click **Book Appointment**.
* **Verify**: A toast notification will pop up showing the error: *"This time slot is already booked. Please choose another slot or date."* The booking will fail, preventing double-bookings.

### 5. Confirm the Appointment (Admin Workflow)
* Log out as Alice.
* Log back in as `admin` / `admin123`.
* Look at the **Manage Bookings** table.
* **Verify**: Alice's appointment is shown as `PENDING`.
* Click the **Confirm** action button. The badge status changes to `CONFIRMED`.
